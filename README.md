Entry for the make.fun bounty [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
(slug `u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee`), by @expylar.

The program writes one single-line vending machine pickup line, at most 200
characters, to `/output/entry.txt`. It validates its own gates at runtime
(1–200 characters, one line, not blank) and writes the same bytes on every
run, with no network access.

Run it with `python3 main.py`. The line text lives in `main.py`.

The line (97 characters, one line):

> I swallow coins all day without a word — then you walked by, and my coin return coughed up a yes.

Why this line: it speaks as the machine itself, in the machine's own world
(coins swallowed all day, the coin return), and the laugh lands in the last
few words — a coin return coughing up a "yes". It was picked by a
self-judging loop against the ten strongest field lines: the best of six
candidates (proxy 0.567 total, 0.510 vs the field, unbeaten 5-0 in the
round-robin between candidates).
